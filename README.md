# estudo_imobiliario_notebooklm
Estudo feito com base nas informações da empresa Plano&Plano afim de me familiarizar com a ferramenta do Google NotebookLm

# Objetivo
  Esse estudo teve como objetivo explorar a ferramenta do NotebookLM, e para isso escolhi um tema que faz parte do meu cotidiano, imóveis na planta.

# Fontes
  Como fonte para esse trabalho utilizei BOOKS (Documentos em PDF com as informações dos projetos), tabela de valores dos empreendimentos e tabela base de financiamento. Todas as fontes utilizadas podem ser encontradas na pasta FONTES desse repositório.

# Engenharia de Prompts
  A ferramenta foi utilizada para consolidação de dados e análise de cenários a seguir:
 - Verificar a renda mínima para que seja possível adquirir cada um dos projetos apresentados.
 - Identificar as unidades NR (Não Residenciais) e aplicar a taxa de juros correspondente, utilizado como base 11,49% a.a. (SBPE).
 - Criar vídeo de análise geral, utilizando como base a região da Zona Leste de São Paulo.
